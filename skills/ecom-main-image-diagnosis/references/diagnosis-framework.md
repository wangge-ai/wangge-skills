# Diagnosis Framework

## The Four Decisions

A main image must help the buyer finish four decisions quickly:

1. Notice: this card interrupts the scroll or shelf scan.
2. Understand: the product category and core use are obvious.
3. Believe: the promise has a proof cue or credible reason.
4. Choose: it has a sharper reason than nearby alternatives.

## Click-Gap Map

| Gap | Diagnostic Question | Common Fix |
|---|---|---|
| Recognition | Can the buyer tell what it is in one glance? | Bigger product, cleaner crop, simpler background |
| Benefit | Is the buyer outcome concrete? | Rewrite attribute into outcome or use case |
| Trust | Is risk reduced before click? | Add visible proof, material cue, service cue, real scene |
| Difference | Does it avoid the category's visual sameness? | Change angle, color role, scene, hook, or proof |
| Focus | Does the eye know where to land first? | Reduce labels, separate product and copy, set hierarchy |
| Platform | Does it fit the traffic scene? | Adjust density, realism, price signal, content tone |
| Claim Risk | Are ranking, efficacy, technology, celebrity, or discount claims visibly supportable? | Add source cue, downgrade claim, move proof to later image |

## Scorecard

Use a 1-5 score only when the user asks for a formal diagnosis or comparison.

| Dimension | Weight | What 5 Means |
|---|---:|---|
| Recognition | 20% | Category and product are clear at shelf speed |
| Click Promise | 25% | Buyer benefit is specific and worth entering |
| Proof And Trust | 20% | Risk is reduced with visible credible cues |
| Shelf Difference | 20% | It stands apart without becoming confusing |
| Execution Clarity | 15% | Composition, copy, color, and hierarchy work together |

Interpretation:

- 4.3-5.0: strong, test small variants.
- 3.5-4.2: usable, one or two gaps limit click.
- 2.5-3.4: weak, needs focused redesign.
- below 2.5: rebuild the click strategy.

## Minimum Viable Change

For each recommendation, write:

```text
Change:
Why:
Expected signal:
Risk:
How to test:
```

Prefer one changed variable per variant. Avoid vague advice such as "more premium", "more eye-catching", or "optimize layout" unless followed by visible execution detail.

## What To Add Beyond Standard Main-Image Diagnosis

Add these when relevant:

- Title-image alignment: does the image prove the title's first selling point?
- Shelf density: is the design too quiet or too noisy for the platform?
- Price expectation: does the image look cheaper or more expensive than the price band?
- Proof cost: which trust cue is cheapest to add now?
- Reshoot threshold: when editing is no longer enough and a new product photo is needed.

## Claim Density And Proof Risk

Use this checkpoint for oral care, cosmetics, food, health, mother-and-baby, cleaning, appliances, and other categories where visible claims can create compliance or trust risk.

Flag the image when it stacks too many unsupported claims in one first image:

- ranking: `TOP1`, `No.1`, `销量第一`, `热卖榜`
- efficacy: `几天变白`, `提升X%`, `去黄`, `修复`, `抗菌`, `除菌`
- technology: named technologies without explanation or source
- celebrity or same-style hooks
- extreme discount or bundle claims
- platform-like badges that are not clearly official

For each flagged claim, label it:

| Label | Meaning | Action |
|---|---|---|
| Visible proof | Source or proof cue is visible | Keep, but avoid clutter |
| Needs source | Claim may be true but source is not visible | Ask for evidence or add proof module |
| Overloaded | Too many claims compete | Keep one primary claim and move others later |
| Risky wording | Claim may be too absolute or regulated | Downgrade wording and ask for compliance review |

Do not verify legal compliance from a screenshot alone. Say what needs source confirmation.

## Same-Category Comparison Mode

When the user provides two or more products in the same category, compare them by decision role, not just aesthetics:

| Dimension | Product A | Product B | Useful Test |
|---|---|---|---|
| Shelf impact | | | Which gets noticed faster? |
| First promise | | | Which promise is easier to understand? |
| Proof clarity | | | Which claim feels more believable? |
| Offer clarity | | | Which purchase benefit is clearer? |
| Visual crowding | | | Which image has fewer competing messages? |
| Title-image alignment | | | Which image proves the title better? |

End with what each product should test next. Do not declare a winner unless the available evidence supports it.
