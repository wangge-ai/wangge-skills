# 提示词与设计简报

## 写提示词前先确认

只确认会影响画面的关键细节：

- 目标平台和图片比例
- 是否必须保留真实产品形状、包装和品牌位置
- 用户是否有产品白底图、透明 PNG、Logo 或证明素材
- 文字是让模型生成，还是后期在设计软件里添加
- 图片用途是主图、广告创意、小红书封面，还是详情页模块

## 设计简报规则

写成可执行、可编辑的画面指令：

- 产品占画面的比例
- 产品位置和裁切方式
- 背景类型和景深
- 文案块位置和最大字数
- 色彩角色：底色、强调色、警示色、证明色
- 证明素材的位置
- 安全区
- 版本测试假设

Bad:

```text
Make it more premium and stronger.
```

Good:

```text
把产品从画面左中移到居中偏右，放大到约占画面高度 58%，删除三个小徽章，只保留右上角一个信任提示，并在左侧预留约 25% 的单行主文案区域。
```

## AI 图像提示词结构

中文电商报告里，AI 图像提示词默认用中文写。只有在用户明确要求英文、目标工具明显更适合英文，或报告用于海外/非中文电商场景时，才输出英文提示词。

```text
画布：
产品：
场景：
构图：
光线：
材质与质感：
文案区域：
风格：
避免：
后期处理：
```

涉及中文文字时，要明确选择处理方式：

- 如果中文文案必须准确，建议在设计软件中后期添加。
- 如果速度比精确排版更重要，可以让图像模型生成短中文短语，但必须检查结果。
- 可分享的中文报告中，提示词要让国内运营和设计师读得懂；除非有明确理由，不要留下长段英文提示词。

## 合规边界

不要生成或暗示：

- 虚假的认证、报告、专利、医生、机构、政府标识、奖项、榜单或销量证明
- 竞品商标、包装、模特、口号或高度相似版式
- 无证据支撑的功效、医疗、食品、儿童安全或金融类声明
- 虚假用户评价或虚假平台徽章

如果证据存在但不可读，标注“需要来源确认”。
