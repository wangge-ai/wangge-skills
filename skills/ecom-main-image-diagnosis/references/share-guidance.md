# Share Guidance

Use this when preparing a public article, share package, or handoff around this skill.

## Public Article Shape

Lead with the result:

1. What the skill helps finish.
2. What input it accepts.
3. What output it produces.
4. One concrete before/problem/change example.
5. What it refuses to overclaim.
6. Where the share package files are.

Avoid backstage writing:

- Do not open with author/date/original-tag lines.
- Do not write like a process log.
- Do not spend the public article on failed attempts, commands, or debugging.
- Move setup notes, validation commands, and blocked attempts into README or handoff docs.

## Source-Neutral Release Check

Before sharing, search the package for:

```text
author names, source toolbox names, contact handles, private version labels, generated-by footers, license blocks, external marketplace names
```

If any are present in public-facing files, remove or rewrite them. Keep source evidence only in private audit notes.

## Share Package Contents

Recommended:

- skill folder
- one clean sample report
- short README for installation and usage
- validation record
- optional article draft

Do not put temporary source files, external restricted packages, private evidence, or copied examples in the share package.

## Reader Input Modes

When the share package contains a main-image/detail-page diagnosis workflow, present two clean input paths:

### Option A: Product link acquisition

Use when the reader wants the workflow to try collecting public product images.

Ask for:

- product link
- platform
- category
- whether a visible, user-controlled logged-in browser may be inspected if the public route is blocked

Promise only:

- public main-image/detail-image acquisition when available
- blocked-state reporting when login, verification, risk control, or empty page shells prevent collection
- a diagnosis report based only on successfully collected or provided visual material

### Option B: Reader-provided assets

Use when crawling is not available or the reader already has design materials.

Ask for:

- 1-5 main images
- first 5 detail-page images or screenshots
- product title
- price band
- target platform
- claim sources for rankings, sales, patents, tests, efficacy, and third-party institutions

Promise:

- main-image click diagnosis
- detail first-five-image conversion support diagnosis
- designer execution checklist
- Chinese AI image-editing prompts

Do not imply real-time monitoring, guaranteed crawling, or guaranteed CTR/CVR lift.
