# Open Report Fallback

当任务未知、非电商或无法稳定分类时，不立即新增正式报告类型，也不强行套用已有模型。

## 开放式报告十步流

1. 提取报告需要支持的实际决策。
2. 确认分析对象、阅读者和使用场景。
3. 区分事实、指标、观点、假设和未知项。
4. 建立临时问题树。
5. 判断任务更接近描述、解释、比较、预测还是决策。
6. 选择最小够用的模型组合。
7. 输出第一阶段分析方案。
8. 在报告中保留证据边界和待验证项。
9. 记录本次路由。
10. 同类任务稳定重复出现后，再登记为正式报告类型。

## 最小正文结构

> 背景与目标 → 范围与口径 → 已知事实 → 关键发现 → 原因或解释 → 备选方案 → 建议 → 风险与未知项 → 验证计划

## 八项最低保障

无论是否存在专用模型，未知报告都必须回答：

1. 报告帮助谁做什么决定。
2. 当前有哪些可信事实。
3. 事实之间有哪些关系。
4. 哪些解释有证据，哪些只是猜测。
5. 存在哪些备选判断或方案。
6. 当前最合理的有限结论是什么。
7. 下一步需要验证什么。
8. 结论错误可能造成什么影响。
