# Model Selector

## Four-layer model table

| 层级 | 作用 | 示例 |
|---|---|---|
| 思考模型 | 怎样拆解和推理 | MECE、第一性原理、归纳演绎 |
| 商业框架 | 从哪些业务维度分析 | STP、4P、波特五力、价值链 |
| 数据方法 | 怎样处理和验证证据 | 趋势、漏斗、分群、相关和实验 |
| 表达结构 | 怎样呈现结论 | 金字塔、问题—证据—建议 |

## Default composition rule

默认组合为：**1 个核心思考模型 + 1 个业务框架或数据方法 + 1 个表达结构**。通常使用 2—4 个工具；每个工具必须对应明确的分析输出。

## Analysis-action selector

| 分析动作 | 推荐工具 |
|---|---|
| 描述发生了什么 | MECE、描述性统计、趋势、结构占比、金字塔 |
| 解释为什么发生 | 问题树、第一性原理、5 Why、鱼骨图、漏斗、U 型思考 |
| 发现规律和需求 | 归纳演绎、用户分群、RFM、评价编码、主题聚类、队列分析 |
| 比较谁更适合 | 基准对标、评分矩阵、决策矩阵、成本收益、归纳演绎 |
| 判断是否值得 | 第一性原理、成本收益、盈亏平衡、风险矩阵、敏感性分析 |
| 预测接下来怎样 | 时间趋势、移动平均、季节性、情景分析、敏感性分析 |
| 规划下一步 | 5W1H、目标差距、路径拆解、优先级矩阵、资源约束 |
| 复盘做得怎样 | 目标差距、归因、假设验证、经验归纳、行动闭环 |

## Nine default analysis chains

| 报告类型 | 默认分析链 |
|---|---|
| 监测型 | MECE 指标体系 → 趋势与结构 → 金字塔输出 |
| 诊断型 | 问题树 → 漏斗或因子拆解 → 根因验证 → 行动 |
| 洞察型 | 样本整理 → 分类编码 → 归纳规律 → 深挖 → 验证 |
| 比较型 | 统一口径 → 对标维度 → 差异 → 边界 → 建议 |
| 评估型 | 标准 → 权重 → 证据评分 → 风险校正 → 结论 |
| 决策型 | 目标 → 备选方案 → 成本收益 → 风险 → 建议 |
| 预测型 | 历史基线 → 趋势 → 情景假设 → 区间 → 监测条件 |
| 规划型 | 目标差距 → 路径 → 资源 → 优先级 → 里程碑 |
| 复盘型 | 目标 → 结果 → 差距 → 原因 → 经验 → 动作 |

## Commercial-framework boundaries

| 框架 | 适用场景 |
|---|---|
| SWOT | 汇总内部优劣势与外部机会风险 |
| PEST | 宏观环境和长期市场变化 |
| STP | 市场细分、目标人群和定位 |
| 4P | 商品、价格、渠道和推广策略 |
| 波特五力 | 行业竞争结构和进入判断 |
| 价值链 | 成本、能力和流程环节分析 |
| 杜邦分析 | 企业级利润和资本效率 |
| BCG 矩阵 | 多业务或多产品组合管理 |
| KANO | 用户需求优先级 |
| RFM | 已有交易用户价值分层 |

只有报告问题确实需要时才加载商业框架，不能为了展示专业性整套罗列。
