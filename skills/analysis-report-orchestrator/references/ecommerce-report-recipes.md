# Ecommerce Report Recipes

每份配方都要将输出限制在可用证据支持的范围内；缺少配方所需事实时，明确标注证据边界，而不补写数据。

## 1. 经营报告

> 指标树 + 趋势分析 + 贡献度分析 + 金字塔

回答整体结果、变化来源、核心问题和下一周期动作。证据边界：结果与贡献判断以已提供的指标口径和时间范围为限。

## 2. 商品与 SKU

> 商品生命周期 + ABC 分类 + 四象限 + 盈利分析

识别引流款、利润款、潜力款、滞销款和清退对象。证据边界：分类与盈利判断需要销量、成本或利润等相应资料；缺失项不得推断。

## 3. 竞品报告

> 基准对标 + MECE + 归纳演绎 + 差异化分析

竞品销量、价格和市场份额不能验证时，必须标注数据状态。证据边界：只比较统一口径下可核对的商品、价格、卖点、页面或评价资料。

## 4. 用户与 VOC

> 用户分群 + 评价编码 + 归纳演绎 + U 型思考

区分用户原话、问题频次、深层原因和产品动作。证据边界：原话和频次仅覆盖提供的样本，深层原因属于需说明依据的推断。

## 5. 投放报告

> 漏斗分析 + 因子拆解 + 边际收益 + 假设验证

除 ROI 外，还要检查曝光、点击、转化、客单、毛利和退款。证据边界：不能用同步变化直接证明投放导致结果变化。

## 6. 内容视觉报告

> 对标分析 + 内容编码 + 归纳演绎 + 创意发散

视觉判断结合信息层级、卖点表达、用户场景和测试结果，不只依赖主观审美。证据边界：页面或截图只能支持其中可见的内容，测试效果需有对应数据。

## 7. 库存供应链

> ABC 分类 + 周转分析 + 需求情景 + 风险矩阵

区分缺货、积压、交付和现金占用风险。证据边界：库存和交付判断以库存、补货、周转或履约资料为限。

## 8. 财务利润

> 成本结构 + 贡献毛利 + 盈亏平衡 + 敏感性分析

GMV 增长不能直接代表利润改善。证据边界：毛利、净利和保本点结论必须使用已提供的成本、费用和收入资料。

## 9. 新品立项

> 市场需求 + 用户问题 + 竞争空间 + 单位经济模型 + 风险评估

模型不能替代市场和用户证据。证据边界：没有市场、用户、竞争或单位经济资料时，只能形成待验证假设与补充清单。

## 10. 活动复盘

> 目标差距 + 流量转化漏斗 + 归因分析 + 行动闭环

区分活动带来的增量和自然发生的销量。证据边界：没有对照、历史基线或归因证据时，不把相关变化写成活动增量。
