# 技术讲解动画

用 Manim 处理公式和系统逻辑，用 HyperFrames 组织时间线、字幕及混合素材。

## 开始使用

将本目录完整复制到 Agent 使用的 Skills 目录，然后请求：

> 使用 $manim-hyperframes-video。把这个技术概念拆成动画分镜，确定哪些画面用 Manim，哪些用时间线合成，并给验片要点。

详细步骤：[SKILL.md](SKILL.md)。[安装说明](../../README.md#安装)。

## 输入与依赖

需另装 Manim、FFmpeg、Node/HyperFrames；MathTex 需 LaTeX。只有实际渲染及验片后才能称成片。

以用户指定的项目目录保存输出。示例中的 `inputs/`、`outputs/` 是可替换位置。包内不附带业务数据、个人账号、客户端安装程序或 API 密钥。
