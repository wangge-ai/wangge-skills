# 关键词校准方法论（skill 的核心防错手册）

朴素关键词分类会静默地给出错误结论。本文件固化真实运行中踩过的坑与对应的校准
实现，供每次复用时直接照搬。词表以"儿童牙膏"为例演示，但**部署到新品类时务必按
目标品类重写词表**，不要直接套用。

---

## 1. 否定感知助手 `neg_aware()`

任何"命中即判定情感/主题"的逻辑都必须先过这个函数。命中词前 1–2 字若含
`不 / 没 / 无 / 别 / 未`，视为否定，返回 `None`。

```python
import re

def neg_aware(text, phrases):
    """返回第一个未被否定的短语命中；否则返回 None。"""
    for p in phrases:
        for m in re.finditer(re.escape(p), text):
            pre = text[max(0, m.start() - 2):m.start()]
            if not re.search(r'[不没无别未]', pre):
                return p
    return None
```

### 真实误判 → 修正对照

| 原短语 | 误判为 | 真实语义 | 处理 |
|---|---|---|---|
| `辣` | 负面 | "不辣嘴"→正面 | 用 `neg_aware`，且只认 `辣嘴/辣嗓子/偏辣` |
| `小了` | 负面 | "黑点明显小了"→正面 | 删除 `小了`，改用 `黑点…变淡` 短语 |
| `性价比` | 负面 | "性价比高"→正面 | 只认 `性价比低/性价比不高` |
| `智商税` | 负面 | "怕又是智商税，结果真香"→正面 | 删除 `智商税` |
| `苦` | 负面 | "一口烂牙深知看牙的痛苦"→无关 | 删除单字 `苦` |
| `好看` | 包装 | "牙白净好看"→效果非包装 | 删除 `好看`，只认 `包装/泵头/礼盒` |
| `黄/白/亮` | 去黄 | "明白/白天/亮了"→无关 | 改用 `黑点/牙黄/变白/亮晶晶` 多字短语 |
| `不爱/抗拒` | 口味负面 | "之前因黑牙不爱笑、抗拒刷牙"→购买前状态，非本品抱怨 | 删除模糊词，只认真·口味负面词 |

## 2. 各步校准词表示例（儿童牙膏，仅供示范）

### Step 3 主分类 / 多标签
- 质量: `黑点, 牙黄, 变白, 防蛀, 龋齿, 蛀牙, 牙渍, 牙结石, 牙菌斑`
- 使用体验: `味道, 口味, 草莓, 牛奶, 甜橙, 孩子爱刷, 抢着刷, 不抗拒, 喜欢刷, 吞咽, 低泡, 温和, 不辣`
- 价格: `价格, 便宜, 划算, 性价比, 贵, 实惠, 物超所值, 分量, 量少, 优惠, 活动, 促销, 小贵, 偏贵`
- 包装: `包装, 泵头, 按压, 礼盒, 外观, 管子, 瓶子`
- 售后服务: `客服, 退换, 换货, 物流异常, 漏发, 少发, 跟进`（注意：`换牙期` 的"换"不算售后）
- 情感正: `满意, 喜欢, 推荐, 回购, 赞, 不错, 好用, 很好, 值得, 惊喜, 放心, 安心, 温和, 不辣, 不抗拒, 有效, 改善`
- 情感负（仅 `neg_aware` 命中）: `辣嘴, 偏辣, 分量少, 量少, 太少, 失望, 后悔, 踩雷, 退货, 差评, 没效果, 抗拒`（去掉被否定前缀的）
- 情感混合信号: `但, 不过, 但是, 唯一, 美中不足, 除了, 稍, 略微, 一点点, 有点, 略`

### Step 4 需求场景（多标签，一条可多命中）
`防蛀护齿(防蛀/龋齿), 口味吸引(味道/草莓/孩子爱刷), 含氟安全(奥拉氟/含氟/国标),
朋友口碑(推荐/朋友说), 牙医推荐(牙医/医生/诊所), 复购(回购/一直用/长期),
解决抗拒刷牙(不爱刷/配合/习惯), 促销囤货(活动/囤/优惠), 多孩二胎(二宝/二胎/兄妹)`

### Step 5 正面满意因素 / 负面关键词
- 正面因子（多字短语）: `去黄/去黑点·牙变白(黑点/牙黄/牙齿白/变白/亮晶晶/牙渍/洁白)`,
  `口味好·孩子爱刷(味道好/草莓味/孩子爱刷/抢着刷/不抗拒)`,
  `成分安全·奥拉氟(奥拉氟/含氟/国标/专业)`, `防蛀护齿见效(防蛀/没新蛀/牙齿健康)`,
  `专业背书(牙医/测评/牙科)`, `复购·长期信赖(回购/一直用)`, `温和不辣(温和/不辣/低泡/吞咽安全)`
- 负面关键词（必须 `neg_aware`）: `分量/支数偏少(分量少/量少/支数少)`,
  `价格偏高·性价比弱(贵了/偏贵/小贵/不划算/有点贵)`,
  `物流偏慢(物流慢/发货慢/快递慢/到货慢)`,
  `见效偏慢·需坚持(有点慢/改善慢/坚持用才/见效慢)`,
  `宣传/预期落差(以为是进口/结果是国产/宣传夸张)`

### Step 6 参照物
- 模糊竞品: `其他牌子, 别的牌子, 之前用的, 之前一直用, 普通牙膏, 网上买的, 超市买`
- 明确竞品: 仅当评论字面出现品牌名才计入（不臆造）
- 同店 SKU/价格档: `两支, 三支, 套装, 组合装, 划算, 囤货, 一箱, 活动价`
- 跨品类互补: `牙线, 牙刷, 漱口水`（通常不是威胁，是互补）
- 本品旧版: `旧版, 老版, 旧规格, 老包装, 升级, 新版, 改版`（儿童牙膏实测=0，属正常）

## 3. 计数规则

- **每条评论每主题唯一**：同一主题下多个短语只计 1 次。
- **主分类去重**：多主题命中时按优先级（如 质量 > 使用体验 > 价格 > 包装 > 售后）
  取首个作为主分类；其余进多标签。
- **多标签用 `;` 连接**，便于后续拆分交叉分析。

---

## 4. 趋势 vs 个别 的判定阈值（Step 5 第三部分）

问题样本量较小（如 <100 条）时，几乎所有单项都低频。明确阈值：
- 设 `问题评论` = 情感为 负面 + 混合 的评论数。
- **趋势** = 某负面关键词占问题评论比例 ≥ 8%（可在品类差异大时调整）。
- **个别** = 低于阈值，仅作提示，不在结论中放大。
- 切勿把"≥3 条"直接当成趋势——小样本下这会把个别当趋势。

---

## 5. 验证清单（每个分类 pass 之后必做）

1. 拉出每个主题命中的 5–10 条原话肉眼核对。
2. 确认否定感知已生效（搜 `不/没` + 关键词，确认未被计入）。
3. 确认单字裸词已替换为多字短语。
4. 确认主分类与多标签数量自洽。
5. 确认"其他/无法判断"占比合理（不要过高，过高说明词表覆盖不足）。
