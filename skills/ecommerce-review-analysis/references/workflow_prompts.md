# 工作流提示词模板（提示词 1–7）

直接复制给模型或作为分步指令。每个提示词都对应 `SKILL.md` 里的一个步骤。
使用前请把 `{{占位符}}` 替换为真实文件路径/字段名。

---

## 提示词 1（数据质量检查）

```
请对我上传的评论数据 {{file}} 做一次数据质量检查，并输出《数据质量检查表》：
1. 统计原始总行数和有效评论数；
2. 检查评论内容、评论人、时间、规格、评分等字段是否完整；
3. 识别空评论、默认评价（如"未填写评价内容"）；
4. 识别是否混入其他商品或其他 SKU 的评论；
5. 如果有追评也要一并分析；
6. 最后给出后续分析建议采用的有效样本口径。
请先输出检查结果和建议排除规则，等待我确认后再做数据处理。
```

## 提示词 2（清洗 / 删除无用评价）

```
请按上一步确认的排除规则生成清洗后的新表格：
- 删除：默认/模板初评、疑似非目标商品或评论过短无实质内容、关键字段缺失；
- 保留：追评单独成"追评子样本"；若唯一差评被长度规则误删，请提示并可恢复；
- 输出：清洗后评价数据（有效评论 + 追评子样本）+ 已删除明细（含原因）。
```

## 提示词 3（结构化分类）

```
请对有效评论进行结构化分类，并生成新的 Excel 文件。为每条评论输出：
评论内容｜主分类｜多标签分类｜情感倾向｜判断依据｜评论时间｜已购规格｜评论人
说明：
- 主分类只能选一个（按最核心话题）：质量、价格、包装、使用体验、售后服务、其他。
- 多标签可选多个，用分号隔开。
- 情感四档：正面（明确满意/认可）、混合（同一评论既认可又提出问题）、
  负面（明确不满/拒绝复购/严重问题）、其他（拿不准就归其他，别硬猜）。
```

## 提示词 4（购买人群与需求场景）

```
基于分类母表，做购买人群与需求场景分析：
1. 买家身份：识别并归类每条评论的购买身份，饼状图呈现数量与占比；
2. 需求场景：提炼主要使用场景，条形图统计各场景频次（一条评论可多场景）；
图表要求：含清晰标题、各类别标注数量与占比、无法判断归"其他"、基于真实内容不臆测。
最后总结：①最主要的购买人群是谁？②最高频使用场景是什么？
```

## 提示词 5（正面 + 负面归因）

```
基于母表，对标记为正面/混合、负面/混合的评论归因，帮助找到口碑来源与优化机会。
第一部分 正面口碑来源：满意因素｜出现频次｜占有效样本比例｜代表性原话｜说明的产品优势｜可放大的品牌表达
第二部分 负面问题归因：负面关键词｜出现频次｜占问题评论比例｜代表性原话｜用户真实痛点｜可优化机会点
第三部分 可执行优化清单：①最核心口碑驱动？②最需优先解决的负面问题？哪些是个别、哪些是趋势？
  ③下一步最值得优化的三个方向？
注意：结论必须来自真实评论；每结论尽量配原话；不放大低频个别；不臆测未明确表达的信息。
```

## 提示词 6（参照物 / 竞品提及）

```
做参照物提及分析，识别用户心中的主要对手与差异化机会：
1. 识别评论中对其他品牌/产品/替代选择的提及：明确竞品品牌、"别家"等模糊竞品、
   跨品类替代品、本品旧版旧规格、同店其他 SKU/价格档；
2. 统计参照物提及频次，列 Top 竞品；
3. 提取每个竞品被提及时的代表原话；
4. 分析对比维度（价格/效果/口感/包装/体验/复购/服务）、用户更认可哪方及原因；
5. 总结差异化切入点。
输出列：参照物类型｜名称或描述｜提及频次｜对比维度｜代表原话｜用户倾向｜差异化机会。
若无明确竞品品牌，直接写"未发现明确竞品品牌"，不编造品牌名。
```

## 提示词 7（可视化报告 + Excel 母表）

```
生成《用户评价分析报告》（可视化 HTML）+ 可筛选 Excel 母表。
报告结构：
一、执行摘要（有效评论数、正面率/问题评论率、三条核心结论）
二、分析口径（原始/有效条数、排除规则、情感标准、多标签说明）
三、评论分类与情感分布
四、购买对象与使用场景分布
五、正面评论归因（口碑来源）
六、负面评论归因（可优化机会点）
七、参照物分析及差异化机会
八、整体全局总结
所有图表注明样本量与统计口径。
同时输出：可继续筛选编辑的 Excel 母表。
```
