# AI 与数据分析教学设计

设计大学生 AI 与 Excel、SQL、Python、BI 能力路径、任务训练和学习效果证据。

## 开始使用

将本目录完整复制到 Agent 使用的 Skills 目录，然后请求：

> 使用 $ai-data-training-program-planner。设计 AI 与数据分析课程的能力成长路径，说明任务、错误训练、作品标准和学生进步证据。

详细步骤：[SKILL.md](SKILL.md)。[安装说明](../../README.md#安装)。

## 输入与依赖

纯方法包；建议搭配 deliberate-practice-coach，也可直接按内含八种训练模式执行。

以用户指定的项目目录保存输出。示例中的 `inputs/`、`outputs/` 是可替换位置。包内不附带业务数据、个人账号、客户端安装程序或 API 密钥。
