# 达人精灵 TikTok 自动运营工作流 · 安装配置指南

> 面向读者：拿到本技能后，只需要两步——把技能放进 WorkBuddy，配置达人精灵 MCP 密钥，即可用一句话让 AI 跑完 TikTok 运营流程。

## 你需要准备

1. WorkBuddy（Windows / macOS 均可）
2. 一个达人精灵 MCP Key（找达人精灵官方申请试用或购买，不是 API Key）

## 第一步：安装技能

把 `TikTok自动运营工作流` 整个文件夹，复制到 WorkBuddy 的技能目录：

- Windows：`$HOME/.agents/skills/`
- macOS：`~/.agents/skills/`

复制后重启 WorkBuddy，技能即可被识别。

> 提示：也可以在 WorkBuddy 的「设置 → 技能」入口查看已安装技能是否出现在列表中。

## 第二步：配置达人精灵 MCP

1. 打开 WorkBuddy 的 MCP 配置（设置 → MCP 服务器，或按官方指引进入连接器管理）。
2. 添加一个 MCP 服务（统一入口，包含全部 5 个工具）：

| 服务名（可自定义） | 地址 | 包含工具 |
| --- | --- | --- |
| 达人精灵 MCP | `https://mcp.kolsprite.com/mcp` | 达人、视频、商品、店铺搜索 + 字幕提取 |

3. 认证方式：在请求 Header 中添加 `secret-key`，值为你的达人精灵 MCP Key。

```json
{
  "secret-key": "你的MCPKey粘贴到这里"
}
```

4. 保存并信任这个新服务（连接器管理页右上角的自定义连接入口里点「信任」），使配置生效。

## 第三步：开始使用

在 WorkBuddy 对话中直接输入自然语言指令，例如：

- "用达人精灵查美国区美妆类目，价格 30–50 美元、评分 4.5+、近 7 天销量增长较快，跑完整套选品流程，输出 7 天执行方案。"
- "分析这个 TikTok 账号：<账号链接>，找出内容支柱、爆款公式和未来 7 天改进动作。"
- "研究美国区宠物用品类目，判断是否值得进入，给出差异化定位和前三个验证动作。"
- "提取这个视频的字幕并拆解脚本：<视频链接>，生成一个可复用的新脚本。"

AI 会自动调用达人精灵 MCP 查询真实数据，按固定流程输出结果。

## 常见问题

**Q：提示"找不到达人精灵工具"怎么办？**
A：检查 MCP 服务是否已添加、是否点了「信任」生效；确认密钥无误后重启 WorkBuddy。

**Q：MCP Key 和 API Key 一样吗？**
A：不一样，是两套独立凭证，计费和限额也相互独立，不能混用。MCP Key 只用于 MCP 服务鉴权（secret-key），API Key 只用于直接调用 HTTP 接口（Authorization）。

**Q：查询报"额度不足/超限"？**
A：达人精灵按分钟和月度限额计费，超过会返回对应错误。稍等重试，或联系官方提升额度。

**Q：提示页数超限？**
A：单次请求 `pageNum × pageSize` 不得超过 1000（例如 pageSize 最大 100）。数据量大时会分批查询，只展示 Top 20。

## 安全提示

- 真实 MCP Key 只保存在本地配置中，不要写进文档、截图、聊天记录或发给任何人。
- 本技能只做公开数据查询与分析，不绕过平台限制、不抓取私密数据。
