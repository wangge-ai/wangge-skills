# 全域蒸馏器

先确定输入属于行业、品牌、网站还是话题，再按用户要求选择快速、标准或深度研究。单个网站聚焦具体页面，行业研究需要比较样本；不用一种固定篇幅覆盖所有任务。

使用 [模式说明](references/modes.md) 选择研究范围；首次完整执行时读取 [完整工作方法](references/full-workflow.md) 和 [流水线](references/pipeline.md)。这些文件保留原分享包的 URL 核对、竞品拆解、来源记录及交付细节。

按 [骨架选择说明](references/skeleton-library.md) 使用 assets/skeletons 下的模板；具体卡片模板放在 assets/templates。遇到官网识别或搜索问题，再读 [搜索方法](references/google-search-tactics.md)。有真实输出后用 [反思问题](references/reflection-prompts.md) 复核。

交付包含来源清单、结构化资料、竞品或概念分析、机会与局限，以及可阅读的索引或报告。关键事实保留原文 URL、日期和适用范围；缺失字段写未知。搜索线索与实际读到的正文分开记录。监控配置只是建议，未经用户要求不创建定时任务，也不把建议称为已运行情报系统。
