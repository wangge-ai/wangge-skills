# 前台利润样例口径

这个文件只保留泛化口径，不包含真实公司、店铺、品牌和人员。

## 样例背景

某电商团队每月会看前台利润。后台能导出销售、出库、推广等数据，但成本、运营归属、补单、扣点等信息需要人工维护。

旧流程通常是：

```text
后台/RPA 下载文件
-> Excel 或 PowerQuery 汇总
-> 添加公式
-> 透视表汇总
-> 人工检查异常
```

新流程希望改成：

```text
后台/RPA 下载文件
-> AI 扫描文件夹
-> AI 清洗合并
-> AI 按旧公式重算
-> AI 对账
-> AI 生成工作台
```

## 样例字段

- 日期
- 平台
- 店铺
- 运营
- SKU
- 单量
- GMV
- 商品成本
- 推广费
- 补单金额
- 平台扣点
- 税费
- 财务成本
- 运费
- 佣金
- 前台利润

## 样例分析维度

- 每日趋势
- 店铺利润排行
- 运营利润排行
- 推广费占比
- 亏损明细
- 补单占比
- 新增数据源说明
- 旧表对账说明

## 注意

这只是样例口径。你自己的业务可以完全不同。

重点不是复制字段，而是复制这个顺序：先还原口径，再对账，再展示。
