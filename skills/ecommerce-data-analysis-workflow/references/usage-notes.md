# 使用说明

这套分享包的核心不是某个固定脚本，而是一种做法：先把业务表拆成几类来源，再让 AI 按口径重建一张标准明细表，最后做汇总、对账和展示。

你可以把它用在前台利润、商品利润、投放效率、库存周转、客服售后等类似场景。只要数据能导出成 Excel 或 CSV，就可以照着改。

## 你需要先准备什么

至少准备三类文件：

1. 后台导出的业务明细
   比如订单、出库、销售、投放、退款、库存等。

2. 人工维护表
   比如 SKU 成本、店铺归属、运营归属、扣点、运费、补单、目标等。

3. 旧结果表或校验表
   如果你以前用 Excel 或 PowerQuery 做过，最好把旧结果也给 AI，用来判断新流程有没有算偏。

## 推荐操作顺序

先不要让 AI 直接画图。

更稳的顺序是：

1. 扫描文件夹，识别有哪些表。
2. 让 AI 说明每个表可能是什么来源。
3. 统一字段，比如日期、SKU、店铺、运营。
4. 按你的旧公式重算核心字段。
5. 和旧表对账。
6. 对账通过后，再生成图表和工作台。

## 你要告诉 AI 的关键口径

不同公司的表不一样，所以不要只说“帮我分析一下”。

至少要说清楚：

- 哪张表是后台导出。
- 哪张表是维护表。
- SKU 或商品 ID 必须按文本处理。
- 日期按什么口径统计。
- 利润公式是什么。
- 推广费、成本、运费、补单这些字段分别从哪里来。
- 是否要保留“有费用但无销售”的记录。

## 不要照搬的地方

不要照搬别人的字段名和公式。

前台利润在不同公司可能差很多：有人算运费，有人不算；有人按支付金额，有人按出库货值；有人把补单放在销售里，有人单独扣。你要把自己的业务规则说清楚，AI 才能稳定复现。
