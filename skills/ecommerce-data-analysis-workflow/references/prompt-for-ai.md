# 给 AI 的提示词：从电商利润表到分析工作台

你可以把下面这段发给 Codex，并把自己的文件路径补进去。

```text
我有一批电商经营数据，需要你帮我从下载文件到分析工作台跑一遍。

请注意：
1. 所有原始文件只读，不要移动、删除或覆盖。
2. 输出都放到当前工作区的 outputs 文件夹。
3. SKU、商品 ID、订单号必须按文本处理，不能变成科学计数法。
4. 读取 Excel/CSV 时按表头定位字段，不要假设固定列号。
5. 先做数据扫描和对账，再做可视化。

我的输入包括：
- 后台下载文件夹：{填你的路径}
- 维护表或旧 Excel：{填你的路径}
- 旧结果表或旧汇总表：{如果有就填}

你要完成：
1. 扫描文件夹，说明每个文件可能是什么报表。
2. 自动识别日期、店铺、运营、SKU、数量、销售额、成本、推广费等字段。
3. 清洗合并成标准明细。
4. 按原 Excel 或我提供的业务公式重算利润。
5. 和旧表对账，分成：旧表有新表没有、新表有旧表没有、两边都有但数值不同。
6. 解释差异原因，不要为了对齐旧表直接删除新增有效数据。
7. 生成汇总表、对账表和一个 HTML 工作台。
8. 最后写一份简短 SOP，说明下次如何复用。

如果你发现缺维护表、公式口径不明确、字段无法判断，请先列出问题，不要直接猜。
```

## 可选补充

如果你已经知道利润公式，可以追加：

```text
利润公式为：
利润 = 销售额 - 商品成本 - 推广费 - 补单金额 - 平台扣点 - 税费 - 财务成本 - 佣金 - 运费 + 补单商品成本
```

如果你有 RPA 下载环节，可以追加：

```text
数据下载我已经用 RPA 完成，你只负责读取下载后的文件，不需要登录后台。
```
