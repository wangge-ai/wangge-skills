# Data Preparation

Prepare a product-list table before using this skill.

## Sources

- marketplace plugin export
- platform backend export
- internal competitor table
- manually prepared Excel/CSV

## Required Steps

1. Search or define the target market keyword.
2. Export or prepare the product-list table.
3. Keep original column headers where possible.
4. Do not delete columns before upload unless they contain sensitive business data.
5. Upload the Excel/CSV file and state the category, platform, date, and sample scope.

## Recommended Fields

- 商品标题
- 价格
- 销量/付款人数/收货人数
- 店铺/卖家
- 品牌/店铺类型
- 类目/子类目
- 平台/来源
- 商品链接
- 导出日期/关键词
