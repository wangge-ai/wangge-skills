# Share Guidance

Use this only when turning the skill or a report into a public article, share package, README, or handoff.

## Public Positioning

Lead with the result:

```text
给一张商品表，它先告诉你这类产品哪里挤、哪里还能试、第一步别乱做什么。
```

Do not open with file lists, script names, validation logs, or internal adaptation notes.

## Keep Separate

- Skill instructions: reusable workflow under the local skill folder.
- Report outputs: generated from a user's table.
- README/share package: install path, sample table, known limits.
- Article body: result-first story, report preview, one clear use case.

## Source-Neutral Release Check

Before sharing adapted files publicly, search for:

- external author names
- external contact details
- private version labels
- generated-by footers
- authorization or redistribution text from the source package
- copied report headers or method names
- local private paths that should not appear in public article text

If any appear in public artifacts, remove them or rewrite the artifact.

## Article Angle

For a WeChat article, keep it grounded:

- show the generated market profile or report first
- explain the operator pain: "有表但不会判断"
- use one sample category, not a universal promise
- show what it will not decide without more fields
- end with how to use the skill or package

Do not promise automatic market truth from a single table.
