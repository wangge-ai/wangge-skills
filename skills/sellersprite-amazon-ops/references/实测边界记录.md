# 实测边界记录（内部文档，不进公开文章）

> 记录卖家精灵 MCP 实测中发现的边界、坑和规避方法（2026-08-20 实测）。只用于内部参考，公开文章不出现。

## 1. 排序字段是枚举值，传错会报错

所有工具的 `order.field` 只接受工具说明里列出的枚举值（如 `searches`、`purchaseRate`、`rankPosition`、`trafficPercentage` 等），传未列出的字段会报错。

- 规避：不确定时不要指定字段，用"按搜索量列出"这类自然语言描述，让 AI 自己选合法排序。
- 教训来源：达人精灵项目曾因排序字段触发服务端 500；卖家精灵这里是参数校验报错，不是服务端 500，但同样要避免。

## 2. 增长率排序会出虚高异常词

`keyword_research` 按增长率（`searches_growth` / `searchNearlyCr`）排序时，会返回从 0 起量的异常词（实测出现过增长率 9000% 的"the loyalty game"类词），这些词购买率、商品数、均价字段异常（如均价为 null），**不可作为选品依据**。

- 规避：选品判断以「购买率 + 供需比 + 点击集中度」三件套为主，不看增长率排序。
- 验证：`large dog chew toy`（购买率 21.86%、供需比 1.37）是真实机会词，但在增长率排序下会被异常词淹没。

## 3. 泛词直接丢扩展，相关性不稳

直接把泛词（如 `dog`、`toys`）传给 `keyword_research` / `keyword_miner` 扩展，返回的关键词相关性不稳定（`dog` 会返回 `mens vans shoes` 等无关词）。

- 规避：
  - `keyword_research`：用筛选器组合（minSearches + minPurchaseRate + maxMonopolyClickRate + minSearchNearlyCr），描述为"找月搜索量高、购买率高、点击集中度低的机会词"
  - `keyword_miner`：用 `keywordList` 精准批量查询目标词（只返回传入词的数据），或用具体词根做扩展查询

## 4. keyword_miner 两种查询模式别混用

- `keyword`（扩展查询）：返回该词及其相关词的初始列表，适合挖词库
- `keywordList`（精准查询）：只返回传入关键词的数据（精确匹配），适合选品对比（如对比 3 个候选词）
- 用途不同：挖词库用 keyword，对比选品用 keywordList。

## 5. keyword_order 必须传反向参数

- `reverseType`：W（周）/ M（月），必填
- `date`：W 传 yyyyMMdd 格式且表示当周的周六；M 传 yyyyMM 格式
- `conversionType` 可选：E（转化优质词）/ S（转化平稳词）/ L（转化流失词）/ I（无效曝光词）

## 6. keyword_conversion 输出可能极大

90 天窗口实测单次返回约 350KB+，直接展示会截断。

- 规避：先落盘（保存到文件）再解析，避免截断丢数据。

## 7. traffic_keyword 明细控制条数

- 必须传 `asin` + `marketplace`
- `size` 控制返回条数；数据大时取 Top N 并注明
- `trafficKeywordTypes`（primary 主要流量词 / precise 精准流量词 / preciseLongTail）与 `conversionKeywordTypes`（excellent / stable / lost / invalid）用于分类筛选

## 8. 数据一致性提醒

参考文章 2（水枪手/Refly 版）写的 B08D6Q93C4（狗狗嗅闻垫）价格 $19.99、评分 4.5；实测返回 $11.99、4.3 星（7981 评论、子类目 BSR #16）。引用竞品数据必须以实测输出为准，不抄参考文章。

## 9. 其他

- 查询无结果：放宽筛选条件（搜索量/购买率阈值）后重试，仍无结果如实说明
- 数据量大：取 Top 20-30 展示，提示可分页查看
- 合规：只查询公开可查数据，不绕过平台限制
