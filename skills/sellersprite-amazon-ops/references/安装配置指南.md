# 安装配置指南 · 卖家精灵 MCP

> 面向：需要把卖家精灵 MCP 接进 WorkBuddy 的用户。全程不用写代码，照着点就行。约 5 分钟。

## 准备

- 一台装了 WorkBuddy 的电脑
- 一串卖家精灵 MCP Key（卖家精灵开放平台注册后获取）

## 5 步配置

### 第 1 步 · 拿到你的 MCP Key

1. 打开卖家精灵开放平台：`https://open.sellersprite.com/`
2. 注册/登录后，点击右上角账号 →【我的密钥】→ 创建密钥
3. 复制生成的 Key

> 注意：MCP Key 与 API Key 是两套独立凭证，别拿混了。Key 等同于账号密码，只自己保存，不要发到群里或截图外传。

### 第 2 步 · 打开 WorkBuddy 的「连接器」管理页

1. 打开 WorkBuddy 主界面
2. 点左侧边栏的「连接器」（有的版本叫「连接管理」）
3. 找到页面顶部的「自定义连接器」入口，点进去

### 第 3 步 · 添加 MCP 服务（照抄 4 项）

点「添加服务」，按下表逐项填写：

| 配置项 | 填什么 |
|---|---|
| 服务名 | 卖家精灵 MCP（名字随意，方便自己认） |
| 连接类型 | `streamable-http` |
| 地址 URL | `https://mcp.sellersprite.com/mcp` |
| 请求 Header | 名称填 `secret-key`，值填你的 MCP Key（第 1 步拿到的） |

### 第 4 步 · 点「信任」，让服务生效

1. 保存后回到自定义连接器列表，能看到刚添加的「卖家精灵 MCP」
2. 点该服务右侧的「信任」按钮
3. 信任后能看到卖家精灵的相关工具（关键词市场、流量反查、ASIN 详情等）

> 不点信任 = 白配。很多人卡在这一步：填完保存以为就好了，结果 AI 说找不到工具。保存之后一定要回来点「信任」。

### 第 5 步 · 验证（30 秒）

新开一个对话框，输入：

```
用卖家精灵 MCP 反查美国站 B00CPDWT2M 的流量词
```

- 如果 AI 开始调用工具，并返回带**搜索量、自然排名、PPC 竞价**的真实数据——配好了，直接开用。
- 如果 AI 只给一段没有任何具体数字的"分析"，说明没连上：回到第 4 步检查是否点了「信任」。

## 常见问题

| 问题 | 处理 |
|---|---|
| 找不到卖家精灵工具 | 回连接器管理页确认「信任」状态，或重启 WorkBuddy |
| 提示 Key 无效 | 回开放平台【我的密钥】重新生成，注意复制完整（32 位） |
| 改了配置仍不生效 | 删除该服务后重新添加（官方指引建议） |
