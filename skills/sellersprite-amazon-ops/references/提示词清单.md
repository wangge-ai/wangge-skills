# 提示词清单（10 条增强版）

> 用法：把 `<尖括号>` 内的内容替换成你的类目 / ASIN / 站点即可。可直接复制到 WorkBuddy 或其他 AI 工具使用。每条已标注"解决什么问题"。

## ① 市场选品 · 不知道做什么品

**解决什么**：从一整个类目里筛"搜索量大 + 购买率高 + 头部未垄断"的机会词，给出最值得做的方向。

```
用卖家精灵 MCP 研究美国站<宠物用品>的关键词市场，找出月搜索量高、购买率高、点击集中度低（不被头部垄断）的机会词，每个词给出搜索量、购买率、商品数、PPC 竞价、供需比，最后告诉我这些词对应的产品方向里，哪个最值得做、为什么。数据标注来源和统计周期。
```

## ② 趋势验证 · 这个市场还能进吗

**解决什么**：判断你选的词所在市场是涨还是萎缩；如果萎缩，给出替代方向。

```
用卖家精灵 MCP 查询美国站关键词 "dog chew toy" 的搜索趋势。请给出近几个月的搜索量、购买量以及购买率的月度变化数据，并基于这些趋势数据判断这个细分市场目前是处于上升期还是萎缩期。同时，结合数据走势、市场饱和度、季节性波动以及竞争程度等维度，给出当前是否适合进场布局该关键词的结论与建议，包括如果适合进场应如何切入（例如选品方向、定价或运营节奏），如果不适合则说明主要风险与可替代的关键词方向。
```

## ③ 竞品地图 · 这个品被谁统治

**解决什么**：一张头部竞品对比表 + 价格带 + 打法标签，告诉你这个品被谁统治。

```
用卖家精灵 MCP 分析美国站<ASIN， B00CPDWT2M>的竞品，找出同类目里表现好的竞品 ASIN，整理成表格：品牌、价格、评分、评论数、月销、月销售额、类目排名，并总结这个细分市场的价格带和头部玩家的差异化打法。
```

## ④ 单 ASIN 深度 · 头部为什么卖得好

**解决什么**：一条头部链接的全维度画像 + 五点卖点结构 + 七维"为什么卖得好"分析。

```
用卖家精灵 MCP 深度分析美国站这个商品：<Benebone Wishbone>，输出以下完整数据并据此评估其表现：

数据维度
1. 价格（当前售价及历史价格范围）
2. 评分（星级与评分值）与评论数（总评论数）
3. 类目归属及在该类目下的排名（大类目与小类目）
4. 变体数量（颜色、尺寸、口味等所有变体）
5. Listing 质量分（若有，给出评分及优化建议）
6. 认证标识（Best Seller 徽章 / Amazon's Choice 标识）

内容结构
- 完整标题（逐词展示）
- 五点卖点（Bullet Points）逐条列出，并拆解每条的撰写逻辑（卖点类型、关键词埋点、说服手法）
- 核心图片或 A+ 内容若有，简要说明其呈现策略

深度分析
- 结合以上数据，分析它为什么卖得好，从以下角度展开：关键词布局与搜索流量、差异化卖点、评分评论数量与评价内容、定价策略、类目竞争格局、变体覆盖、品牌背书与标识效应。
- 给出可落地的优化建议，指出其 listing 的强项与潜在短板。

要求数据具体、可量化，分析逻辑清晰，最后以简洁总结收尾。
```

## ⑤ 流量反查 · 头部靠什么词活着

**解决什么**：竞品流量结构明细 + 自然 vs 广告占比 + 健康度判断 + 可借鉴选词方向。

```
使用卖家精灵 MCP 反查美国站竞品 Benebone Wishbone 的流量来源词，按以下要求输出分析结果：

1. 流量词列表：以搜索量从高到低排序，列出该竞品的主要流量来源词。
2. 每个词的数据字段：需包含月搜索量、购买率、自然排名、PPC 竞价、流量占比，并以表格形式清晰呈现。
3. 流量结构分析：总结该竞品的流量主要依赖哪些关键词（头部词、长尾词或品牌词），以及自然流量与广告（PPC）流量的比例分布情况。
4. 洞察输出：基于以上数据给出简要结论，说明其流量健康度和可借鉴的选词方向。

请确保数据真实、字段完整、排序正确，并突出关键指标。
```

## ⑥ 流量结构诊断 · 自然健康还是广告堆量

**解决什么**：竞品流量关键词构成统计 + 流量结构类型判断（自然健康型 / 广告堆量型）+ 新品开发参考建议。

```
请使用卖家精灵（SellerSprite）MCP 工具，针对美国站竞品 <Benebone Wishbone> 进行流量关键词结构分析，并输出一份结构化的诊断报告。具体要求如下：

一、关键词构成统计
1. 查询该 ASIN 的全部流量关键词，给出总数。
2. 按来源维度分类并统计数量：自然搜索关键词数、广告（Sponsored）关键词数、官方推荐关键词（AC/ER/四星推荐）数。
3. 列出各类关键词中的 Top 示例，方便核对分类逻辑。

二、流量结构类型判断
1. 依据自然词占比、广告词占比及推荐词占比，综合判断该竞品属于"自然流量健康型"还是"广告堆量型"。
2. 给出判断依据（如自然词占比阈值、广告依赖程度、关键词覆盖面）和置信度说明。
3. 如数据介于两者之间，说明边界情况并给出倾向性结论。

三、新品开发参考建议
1. 针对该竞品的流量结构特点，提炼对我们做新品（listing 优化、关键词布局、广告投放策略）的具体可执行建议。
2. 说明哪些关键词值得切入、哪些应规避，以及自然词与广告词的差异化打法。

请以清晰的分点报告形式输出结果，数据若缺失请明确标注并说明影响，不要臆造数据。
```

## ⑦ 转化结构诊断 · 哪些词扩、哪些词否

**解决什么**：关键词转化四分类（优质/平稳/流失/无效）+ 可执行的扩词 / 否词 / 降价广告策略。

```
使用卖家精灵 MCP 反查美国站竞品 Benebone Wishbone 近一个月（过去 30 天）的关键词转化结构，并对这些关键词进行四分类：转化优质词、转化平稳词、转化流失词、无效曝光词。其中重点详列转化优质词与转化流失词两类的清单及其转化率、曝光量、点击率等关键指标。

请据此给出可执行的广告投放策略建议，具体包括：
1. 扩词建议：基于优质词拓展相关长尾词、类目词与潜在转化词；
2. 否词建议：明确应否定的无效曝光词与流失词，说明否词逻辑（如高曝光零转化、ACOS 过高）；
3. 降价建议：针对转化平稳但成本偏高的词给出竞价调整方向与幅度参考。

同时输出结论：该竞品整体流量结构是否健康，以及我方后续广告关键词策略应如何优化。要求数据来源明确、分类口径清晰、建议可直接落地执行。
```

## ⑧ 词库搭建 · 从一个词根铺成可运营词库

**解决什么**：基于词根挖出长尾/场景/品类三级词库，并分好 Listing 埋词 vs 广告投放用途。

```
用卖家精灵 MCP，基于核心词（词根，例如 "indestructible dog toy"）挖掘相关关键词，并按照以下要求整理成一份可直接用于运营的词库：

一、关键词分类与维度
1. 将挖掘出的词分为三类：长尾词（如 "indestructible dog toy for large breed"）、场景词（如 "indestructible dog toy for aggressive chewers"）、品类词（如 "tough dog toys"）。
2. 每个关键词需输出以下指标：搜索量、购买率（转化率）、竞争度、相关度。

二、筛选与排序规则
1. 所有词按搜索量从高到低排序。
2. 筛选出同时满足以下条件的词作为"推荐词"：
   - 相关度较高（与核心词主题紧密相关）
   - 竞争度适中（避免竞争过于激烈的红海词）
   - 搜索量达到合理门槛且具备商业价值
3. 明确区分两类用途：
   - Listing 埋词：适合写入标题、五点、描述中的高相关词
   - 广告投放词：适合用于 Sponsored Products 投放的、搜索量和购买率俱佳的词

三、输出格式
以表格或结构化清单呈现，包含：序号、关键词、所属分类、搜索量、购买率、竞争度、相关度、推荐用途（Listing 埋词 / 广告投放 / 两者均可）、备注说明。最后附加一段简短的词库使用建议总结。

请确保数据完整、逻辑清晰，并基于卖家精灵 MCP 返回的真实数据整理输出。
```

## ⑨ 高转化词识别 · 广告投哪些词

**解决什么**：从词库里筛出高价值广告词，按搜索转化率降序排好，标注 SEO/PPC 用途与差异化投放建议。

```
用卖家精灵 MCP 分析美国站关键词 "indestructible dog toy" 的转化情况。请基于卖家精灵平台提供的搜索量、转化率、PPC 竞价（CPC）等指标，筛选出搜索量大、转化率高且 PPC 竞价合理的高价值关键词，按照"搜索转化率"从高到低排序，输出一份可直接投放的词表。

请将结果按以下结构组织：
1. 筛选条件说明：明确你采用的搜索量、转化率、PPC 竞价阈值与合理区间判定标准
2. 高价值词表：按"搜索转化率"降序排列，每行列出关键词、搜索量、转化率、PPC 竞价，并标注推荐用途
3. 投放策略标注：在每个关键词后标明其更适合"自然排名优化（SEO）"还是"广告投放（PPC/Sponsored Products）"，对于两者皆宜的词请同时标注并说明理由
4. 建议优先说明广告投放时应关注的差异化维度（如相关性、竞品竞争度）

请确保词表简洁清晰、可直接用于选品与投放决策，并在最后附上一段简短的分析总结。
```

## ⑩ 全链路方案 · 一句话跑完从选品到上架

**解决什么**：从选品到 Listing 的完整闭环——一句话拿到"做什么、跟谁打、怎么打"的全部答案。

```
请用卖家精灵 MCP 对亚马逊"狗狗耐咬玩具"这一细分类目，完成一轮从选品到上架的完整调研，并输出一份可执行的"从数据到方案"调研报告。具体分四个阶段执行：

第一阶段：市场机会判定（确定做什么品）
进入卖家精灵"关键词市场"，筛选出高搜索量、高购买率、低垄断的机会型关键词，识别蓝海方向，明确要切入的具体产品定位。

第二阶段：竞品分析（头部打法拆解）
基于第一阶段确定的方向，找出该方向下的头部竞品（Top 10-20），分析其价格带分布、评价结构、上架时长、核心卖点与推广打法，给出定价与竞争策略建议。

第三阶段：关键词词库搭建（流量与转化结构）
反查上述头部竞品的流量词与转化词结构，区分核心词、长尾词、场景词与关联词，构建完整的、可落地的关键词词库。

第四阶段：Listing 与广告方案生成
基于前三个阶段的数据，生成 Listing 标题、五点卖点（Bullet Points）文案，以及分层级的广告投放词表（广泛/词组/精准匹配）。

输出要求：
1. 每一步的关键数据均标注来源（如卖家精灵关键词市场、竞品分析等）与统计周期；
2. 报告末尾给出完整的"从数据到方案"总结结论；
3. 结构清晰、可执行，数据与结论一一对应。
```
