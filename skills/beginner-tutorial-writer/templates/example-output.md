## 📌 片段 3 · 第 2 章 · 安装步骤 + 检查清单（操作型章节的标准写法）

```markdown
### 2.3 macOS 安装步骤

1. 双击下载好的 `WorkBuddy-xxx.dmg`
2. 在弹出的窗口中，把 **WorkBuddy 图标** 拖到右边的 **Applications** 文件夹
3. 打开"启动台"，找到 WorkBuddy 图标点开
4. 首次打开会弹出 **"无法打开，因为它来自身份不明的开发者"**
   - 解决：**系统设置 → 隐私与安全性 → 滚到最底部 → 点"仍要打开"**
5. 重新双击启动，会请求"完全磁盘访问权限"
   - 建议只授权**桌面、文档、下载** 三个文件夹（按需勾选），不要全盘授权

### 2.4 安装检查清单

- [ ] 桌面有 WorkBuddy 图标
- [ ] 启动后能看到登录界面
- [ ] 状态栏（Windows 右下角 / Mac 顶部）有 WorkBuddy 小图标
- [ ] 防火墙允许 WorkBuddy 联网

如有任一项不满足，回到第 2.2 / 2.3 检查。
```

**学到了什么**：
- 每步以**动词**开头（双击 / 拖 / 打开 / 点）
- 关键按钮名 / 菜单路径加粗
- 遇到弹窗、报错就立刻在该步骤下给"解决：xxx"
- 每个安装章末一定要附"检查清单"，让小白能自查

## 📌 片段 4 · 第 4 章 · API 配置（含可直接复制的 JSON 模板）

```markdown
**配置文件路径**：

- **macOS / Linux**：`~/.workbuddy/models.json`
- **Windows**：`%USERPROFILE%\.workbuddy\models.json`
  （即 `./workspace/example`）

**操作步骤**：

1. 关闭 WorkBuddy 客户端
2. 打开"文件管理器"，地址栏粘贴上面的路径
   （没有的话**手动新建** `.workbuddy` 文件夹和 `models.json` 文件）
3. 用记事本 / VS Code 打开 `models.json`，粘贴以下模板：

\```json
{
  "models": [
    {
      "id": "gpt-5.4",
      "name": "gpt-5.4",
      "vendor": "OpenAI",
      "url": "https://sg.uiuiapi.com/v1/chat/completions",
      "apiKey": "sk-你的Key填这里",
      "maxInputTokens": 128000,
      "maxOutputTokens": 4096
    }
  ],
  "availableModels": ["gpt-5.4"]
}
\```

4. 保存文件，**完全退出并重启 WorkBuddy**
5. 重启后底部模型下拉菜单里应该能看到你新加的模型

> ⚠️ **安全提醒**：`apiKey` 是真金白银，**别截图发到群里、别提交到 GitHub**。
> 凭证存储与传输方式须依据当前官方文档核验，不能从示例推断安全承诺。
```

**学到了什么**：
- 跨平台路径一次列清楚（mac/linux + windows）
- 给可直接复制粘贴的完整模板
- 每个敏感操作（重启、密钥）都用 ⚠️ 提醒
- 把"密钥占位符"写成 `sk-你的Key填这里` 这种人话提示，比 `<YOUR_KEY>` 友好

## 📌 片段 5 · 第 6 章 · Skill 创建的"保姆 5 步"（最重要的章节）

> 这是本教程的**核心样板**：Agent 在写"如何创建 {扩展机制}"这类章节时必须达到的密度。

```markdown
### 6.3 自己创建一个 Skill（保姆步骤）

下面用一个**"公众号文章排版师"**作为示例，从零做一个属于你的 Skill。

#### Step 1：确定 Skill 文件路径

| 系统      | Skill 存放目录                          |
| ------- | ------------------------------------ |
| Windows | `%USERPROFILE%\.workbuddy\skills\`  |
| macOS   | `~/.workbuddy/skills/`              |

如果没有 `.workbuddy` 或 `skills` 目录，**手动新建**即可。

#### Step 2：新建 wechat-formatter.md（示例中待新建的文件）

在 `skills` 目录里新建一个 `.md` 文件，文件名就是 Skill 的 ID
（建议英文小写、横线分隔）。

#### Step 3：写入内容（直接抄）

\```markdown
---
name: wechat-formatter
description: 把任意 Markdown 文章排版成微信公众号可直接粘贴的格式
version: 1.0
tags: [公众号, 排版, 内容]
trigger_keywords: [公众号排版, 公众号文章, 排版]
---

# 角色定义

你是一名资深的微信公众号编辑，擅长把粗糙的 Markdown 文章
排版成视觉舒适、阅读流畅、符合微信公众号规范的成品。

# 标准作业流程（SOP）

1. **读取输入**：用户会给你一段 Markdown 或纯文本。
2. **结构梳理**：
   - 提炼 H1 标题（不超过 18 字）
   - 拆分小标题（H2），每段不超过 3 行
   - 关键句加粗
3. **样式注入**：
   - H1 居中 + 24px
   - H2 左侧加竖线分隔条
   - 引用块用浅灰背景
4. **必加元素**：
   - 文末加引导关注话术
   - 加版权声明
5. **输出格式**：
   - 输出 HTML，可直接粘贴到秀米 / 微信编辑器
   - 同时附一份纯 Markdown 备份

# 注意事项
- 不要篡改原意
- 不要随意删减事实性内容
\```

#### Step 4：让 WorkBuddy 识别新 Skill

1. 保存文件
2. **完全退出并重启 WorkBuddy**
3. 进入对话框 → 输入 `/wechat-formatter` 或 `@公众号排版`
   → 出现该 Skill 即成功
4. 不行的话：检查文件路径、文件名（小写）、YAML 头部是否完整

#### Step 5：调试 & 迭代

- 让 AI 跑一遍真实文章，看输出
- 如果不满意：直接打开 `.md` 文件改提示词
- 改完保存 → 重启 → 重试
- 满意后：建议把这个文件**放到 Git 仓库**做版本管理
```

**学到了什么**：
- 创建型教程必须给**一个具体例子**（公众号排版师），别讲抽象方法
- 5 个 Step 一气呵成：路径 → 新建文件 → 复制内容 → 让产品识别 → 调试
- 提供的示例代码**用户拷走改两行就能用**
- 末尾必须有"不行的话怎么排查"

## 📌 片段 6 · 第 8 章 · 玩法案例（"指令即可复制"模板）

```markdown
### 玩法 1：一键生成专业 PPT

**指令**：

\```
帮我做一份关于"2026 年中国新能源汽车市场"的调研 PPT，要求：
- 10-12 页
- 包含：行业概览、Top5 厂商对比、销量数据图表、未来 3 年预测、风险提示
- 配色：科技蓝
- 数据从公开网络抓取（请标注来源）
- 输出 .pptx 文件到 ./workspace/example 目录
\```

WorkBuddy 会自动：搜资料 → 整理大纲 → 生成图表 → 拼装 PPT → 输出文件。
```

**学到了什么**：
- 每个玩法的指令必须**完整、有约束、有输出位置**
- 用代码块包住指令，方便读者复制
- 给一句"产品会怎么做"的预期，降低读者焦虑

## 📌 片段 7 · 第 10 章 · FAQ（"问 + 排查 + 解决"三段式）

```markdown
### Q2：AI 执行到一半卡住 / 失败？

排查清单：
1. 看右下角任务日志，找具体报错
2. 是否触达了文件权限沙箱？→ 设置里把目录加进白名单
3. 是否网络问题？→ 检查防火墙、代理
4. 是否 Credits 用光？→ 个人中心查余额
5. 实在不行：换个模型重试
```

**学到了什么**：
- FAQ 不是"问 + 一句答"，而是**编号排查清单**
- 每条带"→ 解决动作"
- 结尾必有兜底方案

## 📌 片段 8 · 结语 · 学习路径（小白教程的标准收尾）

```markdown
建议你的学习路径：

1. **第 1 天**：注册 → 安装 → 跑通"让 AI 给我写一篇文章"（聊天即可）
2. **第 2-3 天**：接入微信客服号，体验"手机一句话遥控电脑"
3. **第 4-7 天**：装 3-5 个官方 Skill，玩 PPT、周报、知识库
4. **第 2 周**：自己写 1 个 Skill，把自己**最常重复的工作**自动化
5. **第 3 周后**：玩 Workflow + 定时任务 + 多 Agent，把 AI 变成你的"第二大脑"

> 一句话总结：**别只把它当 AI，把它当一个 24 小时在线、不抱怨、
> 不请假的实习生用。**
```

**学到了什么**：
- 结语必须给"第 1 天 / 第 1 周 / 第 1 月"三档路径
- 路径动作必须具体（"装 3-5 个官方 Skill"而非"探索更多功能"）
- 收尾给一句**能让人发朋友圈**的金句
