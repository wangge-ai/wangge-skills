# 公众号封面制作

生成留白背景后本地排入准确中文标题，支持多张封面、尺寸与移动缩略图检查。

## 开始使用

将本目录完整复制到 Agent 使用的 Skills 目录，然后请求：

> 使用 $wechat-cover-maker。使用这个背景和准确标题制作公众号封面，检查文字不裁切、不覆盖主体，保留可复用背景。

详细步骤：[SKILL.md](SKILL.md)。[安装说明](../../README.md#安装)。

## 输入与依赖

Python + Pillow 与可用中文字体；背景需用户素材或可用生图工具，HTML 截图备选需浏览器。

以用户指定的项目目录保存输出。示例中的 `inputs/`、`outputs/` 是可替换位置。包内不附带业务数据、个人账号、客户端安装程序或 API 密钥。

## 随包脚本

- [render_cover_text.py](scripts/render_cover_text.py)：先运行 `python scripts/render_cover_text.py --help` 查看参数。
