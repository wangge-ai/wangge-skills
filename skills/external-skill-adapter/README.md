# 外部 Skill 适配

把外部 Skill 或提示词包适配到目标 Agent，核对来源、工具、输出和验证边界。

## 快速使用

从仓库复制 `skills/external-skill-adapter` 整个目录到目标 Agent 的 Skills 目录，再给出实际输入和所需交付物。支持标准 SKILL.md 的环境可阅读此包；各平台的安装位置及工具能力以其官方说明为准。

```text
请用 $external-skill-adapter，根据我提供的资料完成外部 Skill 适配。
先说明输入范围和缺失信息，结论保留原始证据。
```

## 内容与依赖

- [SKILL.md](SKILL.md)：实际执行方法。
- [references/](references/)：配套方法与模板。

文件读写；需要读远程来源时使用用户可用的搜索或浏览器工具。
