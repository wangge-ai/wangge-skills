# AIHot 作为选题发现入口

AIHot 是可选外部来源，入口为 <https://aihot.virxact.com/>。本包只提供维护者的选题整理方法，不转载该站的独立 Skill、日报或资讯语料，也不附带客户端。

## 使用方式

1. 在用户选择的浏览器中打开入口；无法访问时记录失败，转用用户提供的链接或其他公开来源。
2. 记录候选标题、来源、页面显示日期及采集时间。没有显示日期的条目标记为未知。
3. 打开原始发布者的页面，核验事件日期与实际范围；聚合站日期不自动成为事件日期。
4. 同一事件去重，按读者任务、可见证据与制作成本筛选。
5. 输出选题简报。没有实际操作或截图，不写成作者实测。

## 接口与访问边界

仅在站方当前文档明确公开接口及访问条件时，按其文档调用。接口、认证和频率可能变化，本次发布未验证在线接口。访问受限或出现验证码时记录并停止该项，不调整身份规避限制，不保存会话凭据。不把聚合站作为结论的唯一证据。
